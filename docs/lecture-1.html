Lecture notes

Summary

  • A message \(w\in\{1,\ldots,M\}\) is sent as the codeword \(x^n(w)\); the rate is \(R = (\log_2 M)/n\), and \(P_e = P(\hat{\rv W}\ne\rv W)\) is the probability of a wrong message.
  • With a uniform message, the best decoder is maximum likelihood (ML): \(\hat x^n = \arg\max_{x^n\in\Ccal} p(y^n\mid x^n)\). On a memoryless channel it needs, for each channel use, the likelihood function \(a\mapsto p(y_i\mid a)\) up to a factor.
  • Binary input: one number per bit, the log-likelihood ratio \(L = \ln\frac{p(y\mid 0)}{p(y\mid 1)}\). BSC: \(L = \pm\ln\frac{1-\delta}{\delta}\). BEC: \(L\in\{+\infty, 0, -\infty\}\). Soft output: any real \(L\).
  • ML \(= \arg\min_{x^n\in\Ccal}\sum_{i:\,x_i\ne\hat y_i}|L_i|\), where \(\hat y_i\) is the hard decision: each disagreement costs its reliability. Hamming distance on the BSC, consistency on the BEC, weighted Hamming distance on a soft-output channel (equivalently, the nearest point \(\pm 1\) to \(L^n\)).
  • The minimum distance \(d\) guarantees \(\lfloor (d-1)/2\rfloor\) errors on the BSC and \(d-1\) erasures on the BEC.

Exercises

5 problems

  1. Problem 1 An asymmetric channel

    A binary-input channel has output \(y\in\{0,1\}\) with \(p(1\mid 0) = 0\) and \(p(0\mid 1) = \gamma\), where \(0<\gamma<1\): a \(1\) is sometimes read as a \(0\), a \(0\) is never read as a \(1\). Compute \(L(0)\) and \(L(1)\). Describe the ML decoder of the \((n,1)\) repetition code on this channel, and compute its error probability.

  2. Problem 2 Repetition, \(n = 5\)

    Compute the error probability of the \((5,1)\) repetition code with ML decoding on the BSC\((0.1)\). Compare with \(n=3\). What is the probability that the decoder has to guess on the BEC\((0.1)\)?

  3. Problem 3 Hard against soft

    The \((3,1)\) repetition code is used and the receiver computes \(L^n = (+3,-1,-1)\). What does the majority vote decide? What does ML decide? Compute \(P(\rv X=0\mid \rv Y^n = y^n)\) for a uniform bit. (Hint: on a memoryless channel, the LLR of the whole observation is \(\sum_i L_i\).)

  4. Problem 4 Three receivers again

    With the code \(\Ccal = \{00000,\ 01011,\ 10101,\ 11110\}\) of the example in Section 1.4 of the notes, the receiver computes \(L^n = (-3,\ +2,\ +1,\ -1,\ -5)\). Decode with the soft decoder, with hard decisions, and with erasures where \(|L_i|\le 1\).

  5. Problem 5 Detection

    Show that a code of minimum distance \(d\) detects every pattern of \(1\) to \(d-1\) errors on the BSC: the received word is not a codeword. Why can a pattern of \(d\) errors go unnoticed?
