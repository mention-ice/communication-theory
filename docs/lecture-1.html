Lecture notes

Summary

  • With equally likely codewords, the best decoder is maximum likelihood (ML): \(\hat{\xv} = \arg\max_{\xv\in\Ccal} P(\yv\mid\xv)\). On a memoryless channel it needs, for each channel use, the likelihood function \(a\mapsto P(y_i\mid a)\) up to a factor.
  • Binary input: one number per bit, the log-likelihood ratio \(L = \ln\frac{P(y\mid 0)}{P(y\mid 1)}\). BSC: \(L = \pm\ln\frac{1-p}{p}\). BEC: \(L\in\{+\infty, 0, -\infty\}\). Soft output: any real \(L\).
  • ML \(= \arg\max_{\cv\in\Ccal}\sum_i x_iL_i\) with \(x_i = 1-2c_i\): minimum Hamming distance on the BSC, consistency on the BEC, nearest antipodal codeword to \(\Lv\) on a soft-output channel.
  • The minimum distance \(d\) guarantees \(\lfloor (d-1)/2\rfloor\) errors on the BSC and \(d-1\) erasures on the BEC.
