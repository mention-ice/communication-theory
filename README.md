# Communication Theory

Course website: https://mention-ice.github.io/communication-theory/

Lecture notes, tutorials (TD) with their corrections and labs (TP) with their solutions for the course
*Communication Theory* (Sheng Yang, CentraleSupélec, 2nd year, 2026–2027). The page of each session
goes online after the session.

The site in `docs/` is generated by `python3 src/build.py`; do not edit it by hand.

- `src/course.json`: course data and the 19 sessions in teaching order. To put a session online, set
  `"online": true` and `"content": "content/<id>.py"`, then rebuild.
- `src/content/<id>.py`: one page (summary, files, contents, quiz, exercises; solutions are shown only
  for exercises that have a `"solution"` field; TD/TP pages can add `"links"` to interactive pages).
- `src/files/`: PDFs and notebooks linked from the pages.
- `src/assets/`: style and scripts, the same design as the Elements of Information Theory site
  (https://mention-ice.github.io/information-theory/) in the Mention ICE palette.
